# 2-Minute Demo Script

## 1) Problem statement (0:00–0:15)
Many AI/Data job seekers struggle to identify exactly which skills are in demand and what to build next.

## 2) Job Market Overview (0:15–0:35)
Show role, location, and job-type distributions, plus quick market signals from extracted skills.

## 3) Skill Demand Analysis (0:35–0:55)
Highlight top skills, category splits, co-occurrence, and role-wise demand patterns.

## 4) CV Skill Gap Analyzer (0:55–1:15)
Paste a CV snippet, select a target role, and show matched/missing skills with recommendations.

## 5) Project Recommendation Engine (1:15–1:30)
Generate portfolio project ideas based on selected skills and role alignment.

## 6) Role Segmentation + Job Clustering (1:30–1:45)
Run clustering, explain cluster themes, and show role-segment insights.

## 7) Career Explorer (1:45–1:52)
Browse role profiles across 12 career categories — core skills, helpful skills, and recommended actions without needing job data.

## 8) Data Import & Dataset Manager (1:52–1:58)
Upload or import CSV data, validate schema, and process dashboard-ready outputs.

## 9) Final value proposition (1:58–2:00)
CareerCompass turns job-posting text and curated role profiles into actionable career intelligence: market analysis, gap detection, and build-ready project and career action roadmaps.
