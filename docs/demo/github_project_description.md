# GitHub Project Description Assets

## 1) Short repository description (<=350 chars)
A 6-page Streamlit app for AI/Data career intelligence: market overview, skill demand analysis, CV skill-gap insights, project recommendations, role clustering, and CSV import pipeline. Built with Python, Pandas, scikit-learn, Plotly, and tested with pytest.

## 2) Longer GitHub About section
AI Job Market Intelligence + Skill Gap Recommender is a local-first Streamlit application that converts job-posting text into actionable career guidance. It includes skill extraction, CV-to-market gap analysis, recommendation logic, unsupervised role clustering, and a schema-validated CSV import workflow.
