# Portfolio Website Section Copy

## Project Title
AI Job Market Intelligence + Skill Gap Recommender

## Short Description
A 6-page Streamlit application that converts job-posting text into market insights, CV skill-gap diagnostics, project recommendations, and role clusters.

## Problem
AI/Data candidates often lack a structured way to decide which skills to prioritize and what projects to build for role alignment.

## Solution
I built a local-first analytics product that cleans and analyzes job data, extracts skills, compares profile skills against market demand, and recommends practical next projects.

## Features
- Job Market Overview
- Skill Demand Analysis
- CV Skill Gap Analyzer
- Project Recommendation Engine
- Role Segmentation & Job Clustering
- Data Import & Dataset Manager

## Tech Stack
Python, Pandas, NumPy, scikit-learn, Plotly, Streamlit, pytest

## What I Learned
- Building modular pipelines improves maintainability and testing.
- Product UX and validation are as important as model logic.
- Honest constraints (synthetic default data + import support) increase credibility.
