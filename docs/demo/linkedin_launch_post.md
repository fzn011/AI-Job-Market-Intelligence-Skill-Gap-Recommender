# LinkedIn Launch Post

I’m excited to share a project I built: **AI Job Market Intelligence + Skill Gap Recommender**.

Many AI/Data job seekers know they need to “learn more,” but it’s hard to decide *what* to prioritize and *what to build next*.

So I built a full Streamlit product (not just a notebook) that helps with exactly that:

- Job market overview dashboard
- Skill demand analysis
- CV skill gap analyzer
- Project recommendation engine
- Role segmentation with clustering
- CSV import pipeline for custom data

**Tech stack:** Python, Pandas, scikit-learn, Plotly, Streamlit, pytest.

A key design decision was to keep it local-first and transparent:
- Default demo data is synthetic
- Users can import their own CSV job data safely through schema validation
- No paid APIs required

What I learned most:
- Designing modular data workflows matters as much as model logic
- Product-level polish (UX, validation, docs, tests) significantly improves project quality
- Honest constraints and reproducibility are important for real-world credibility

I’d love feedback from data and AI practitioners.
